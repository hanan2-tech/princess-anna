# Princess Anna — Hebrew Dropshipping Store

Neon Glow aesthetic store for girls accessories. Hebrew only. Static site on GitHub Pages.

## Deploy
```bash
git add -A && git commit -m "update" && git push origin main
```
GitHub Pages auto-deploys from main branch.

## Live URL
https://hanan2-tech.github.io/princess-anna

## Stack
- Single `index.html` + `products.json` (35 products)
- PWA (manifest.json + service worker)
- Formspree (xnjobpwo) for orders
- AliExpress CDN for product images
- 12 MP3 sound files

## Brand
- Theme: Neon Glow (pitch black + neon purple/pink/mint/cyan)
- Language: Hebrew ONLY
- Font: Heebo
- Target: 8yo girl, teen aesthetic
